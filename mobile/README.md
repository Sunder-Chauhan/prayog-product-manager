# Prayog Decor mobile (Expo Go)

This native Expo app uses the same Supabase project as the web app. It supports sign-in, products and photos, orders, inventory, purchases, suppliers and expenses.

Copy `.env.example` to `.env` and set the project URL and publishable key. Run `npm ci` then `npx expo start --tunnel`. Scan the QR code in Expo Go on Android. Expo Go is for testing; it needs a running development server. An installable standalone app requires an EAS build and an Expo account.
